# zusat: R Bindings for the 'CaDiCaL' SAT Solver

Solves Boolean satisfiability (SAT) problems using 'CaDiCaL', a modern
conflict-driven clause learning solver. Supports incremental solving,
solving under assumptions, and inspection of which assumptions caused
unsatisfiability. The 'CaDiCaL' C++ sources are bundled, so no external
solver installation is required.
